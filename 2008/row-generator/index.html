무한 row 생성 쿼리

Oracle에서는 다음과 같이 connect by절을 사용해 원하는 만큼 row를 만들어낼 수 있다.

Oracle 9i (1~100까지의 row를 생성)

select * from (select level from dual connect by level <= 100)

Oracle 10g (1~100까지의 row를 생성)

select level from dual connect by level <= 100

진짜 무한 row 생성 쿼리 (10g)

select level from dual connect by 1=1
